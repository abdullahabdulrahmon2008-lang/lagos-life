# lagos-life

Puzzle Master is a browser-based match-3 rescue adventure. Match gems, create
line blasts and burst gems, and help Ayo escape the Shadow Beast across three
increasingly difficult stages.

## Play

Open `index.html` in a modern web browser. No build step or package install is
required.

## Stages

- Stage 1: 600 points and 9 Green Leaves in 14 moves.
- Stage 2: 800 points and 12 Olumo Gems in 11 moves.
- Stage 3: 1,000 points and 15 Star Stones in 9 moves.
